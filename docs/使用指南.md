# 使用指南

還沒安裝的話，先看 [安裝教學](安裝教學-Mac.md)。

## 基本操作

| 想做的事             | 怎麼做                                                                            |
| -------------------- | --------------------------------------------------------------------------------- |
| 說一句話             | 在任何輸入框，**按住右 ⌥ Option**，聽到「叮」再開口，說完放開                     |
| 說一大段（免持）     | **快按兩下**右 Option，膠囊顯示「免持・再按一下結束」後就能放開手說，說完再按一下 |
| 取消這次             | 按 **Esc**（按著說話鍵時也可以）                                                  |
| 貼錯地方、想再貼一次 | 選單列的默契圖示 →「貼上上一次」                                                  |
| 只想複製             | 選單列的默契圖示 →「複製上一次」                                                  |

- 按不到 0.3 秒不會觸發，不怕誤觸。
- 說到一半換了視窗，默契不會把字貼進錯的地方，而是複製起來，膠囊顯示「已複製，請自己貼上」。
- 貼上後，你原本剪貼簿裡的東西會還原。

### 膠囊在說什麼

錄音時，螢幕下方會出現一個黑色膠囊：

- **紅點＋聲波**：正在聽。剛按下時會短暫顯示你正在哪個 App。
- **流光線條**：辨識中。
- **「整理中」**：正在整理，旁邊會寫文字送去哪裡（例如「文字 → DeepSeek」）。翻譯時顯示「翻譯中」，修改選取的文字時顯示「改寫中」。
- **「改寫選取的文字」**：你選取了一段字，這次說的話會用來修改它（見「[用說的修改選取的文字](#用說的修改選取的文字)」）。
- **✓**：貼好了。若顯示「🔒 全程本機」，代表這次沒有任何資料離開電腦。
- **「已複製，請自己貼上」**：中途換了視窗，按 ⌘V 貼到你要的地方。
- **「潤稿沒有完成，已貼上原文」**：網路或潤稿服務出了問題，貼上的是沒整理的辨識結果。

## 三種潤飾程度

在「設定」→「潤飾程度」切換：

| 程度             | 做什麼                                                              | 適合                 |
| ---------------- | ------------------------------------------------------------------- | -------------------- |
| **原話**         | 只加標點、轉繁體、套用字典，一個字都不改。全程本機，放開後約 0.6 秒 | 在意隱私、想保留原樣 |
| **整理**（推薦） | 去掉「嗯、那個」，改口只留最後的說法，口頭列點變清單。不換你的用詞  | 大部分時候           |
| **潤飾**         | 重組句子，讀起來像寫的                                              | 寫信、寫文件         |

同一句話：

> 原話：嗯，就是那個，我覺得這個功能還還不錯啦，不過就是就是有點慢，然後介面的話，我是覺得可以再簡單一點。
>
> 整理：我覺得這個功能還不錯啦，不過有點慢，然後介面的話，我是覺得可以再簡單一點。
>
> 潤飾：我覺得這個功能還不錯，不過有點慢。介面的話，我覺得可以再簡單一點。

「整理」和「潤飾」需要潤稿服務（預設 DeepSeek，要 API key，按用量付費，一般使用每月花費很低）。不想讓文字離開電腦的話，可以改用[本機模型](#潤稿服務)。

## 看場合整理

默契會看你按下快捷鍵時在哪個 App，自動調整整理方式。判斷在你的電腦上完成，送出的只有場合類別。

| 場合       | 哪些 App                                                                                      | 整理時怎麼做                                                   |
| ---------- | --------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 聊天       | LINE、Messenger、訊息、Telegram、WhatsApp、Discord、Slack，以及網頁版的 LINE、Messenger       | 保留口語和語氣詞；最後一句不加句號；不分段、不換行，不會誤送出 |
| 對 AI 說話 | Claude、ChatGPT、終端機、iTerm2、Warp、Ghostty、VS Code、Cursor，以及網頁版的 ChatGPT、Claude | 一個細節都不刪，指令、檔名、程式碼照原樣                       |
| 筆記       | 備忘錄、Obsidian、網頁版的 Google Keep                                                        | 口頭列點變清單                                                 |
| 其他       | 其他所有 App                                                                                  | 一般的整理                                                     |

## 字典

名字、產品、術語常被聽錯的話，在「字典」頁加進去，只寫正確的寫法：

- 加入後，辨識時就會參考：最近用到的 50 個詞交給語音模型，聽到相近的音會往你的寫法靠（在你的電腦上，不送出）。
- 整理時也會照你的寫法，英文大小寫也一樣（例如 `Moqi`、`Claude Code`、`config.toml`）。
- 字典會跟著文字一起送到潤稿服務；「原話」模式不送出任何東西。

### 語音片語

常打的固定內容，可以設成一句話。在「字典」頁的「語音片語」加入「要說的話」和「要貼上的內容」，例如說「我的信箱」就貼上你的 email。

- 整句話剛好是那幾個字才會觸發，句子裡提到不算。
- 片語不經過潤稿服務，直接貼上。

### 從你的修改學習

默契打錯的字，你改一次，下次就寫對。有兩種教法：

- **直接在原地改**：在「設定」→「學習」打開「從我的修改學習」後，你照常在輸入框裡改正、照常送出，默契在旁邊看到就記住。VS Code、Slack，以及 Chrome、Edge、Arc 這類平常不讓別的程式讀輸入框的 App，默契會請它們開放給輔助使用功能讀取。
- **在歷史紀錄裡改**：按一筆紀錄的「修正」，改好按 Enter。不用打開上面的設定，在每個 App 都有效。選單列的「修正上一次…」會直接打開最新一筆。

記住的規則：

- **聽錯的字，改一次就學會**：改成英文詞的（「蘇帕貝斯」→「Supabase」），或讀音相同、相近的中文（「實做」→「實作」、「時辰」→「時程」）。前後鼻音、捲舌與否算相近。
- 英文詞下次被聽成別的同音字（例如教過「深拓」→「Zentro」，下次聽成「申拓」），也會換成你教的寫法。
- **讀音不同的改動，改兩次才學**：例如「但是」→「可是」比較像改說法，改一次就學的話，之後每個「但是」都會被換掉。
- 聽錯的詞也會加進字典，辨識時就會參考，換個錯法也能聽對。
- 學到的改法列在「字典」頁的「學到的改法」，可以刪除；刪除後不會再自動學這一個（在歷史紀錄裡再教一次就會恢復）。改過一次的，可以按「現在套用」。
- 只在這台電腦上比對，只保存改過的詞，不保存整段文字，也不會送出。密碼欄不會讀。細節見 [隱私說明](隱私.md#從你的修改學習預設關閉)。

## 歷史紀錄

保留最近 100 次。點開一筆可以：

- 看辨識原文（整理前的樣子）、播放錄音。
- 看「這次送出了什麼」：送出了幾個字、送到哪裡，哪些沒送。
- **修正**：改掉聽錯的字，按 Enter，默契會記住（見 [從你的修改學習](#從你的修改學習)）。紀錄裡的文字也會換成改好的。
- **重貼**：先點一下你要的輸入框，再回到默契按「重貼」，默契會收起來並貼回那裡。
- 複製、刪除。刪除會連錄音一起刪，首頁的統計也會扣掉。

## 各 App 的風格與翻譯

在「設定」→「語言與各 App 的風格」：

- **翻譯成**：選一個語言，之後不管說什麼語言，都寫成那個語言。預設「照說的語言」。
- **各 App 分開設定**：用默契打過字的 App 會列在這裡，按「調整」可以改三件事。
  - 風格：聊天、給 AI、筆記、一般。預設是默契自動判斷的那一種。
  - 語言：這個 App 要翻譯成什麼語言，或跟隨上面的設定。
  - 額外要求：例如「用敬語」「句子短一點」。
- 瀏覽器裡認得的網站（例如 Facebook、ChatGPT）會各自一列，其他分頁共用瀏覽器那一列。
- 翻譯和額外要求要有潤稿服務才會生效。翻譯時，即使潤飾程度是「原話」，那句話也會送去翻譯。

## 用說的修改選取的文字

在「設定」→「潤飾程度」打開「選取文字時，用說的修改它」。之後：

1. 在任何輸入框選取一段文字。
2. 按住說話鍵，膠囊會顯示「改寫選取的文字」。
3. 說你要怎麼改，例如「改正式一點」「翻成英文」「縮短成一句」；直接說新的內容，則會取代選取的文字。

預設關閉，因為打開後**選取的文字會跟你說的話一起送給潤稿服務**。密碼欄不會讀。

## 潤稿服務

在「設定」→「潤稿服務」選擇誰來整理你的字：

| 服務                              | 需要                  | 文字送到哪裡                       | 適合                         |
| --------------------------------- | --------------------- | ---------------------------------- | ---------------------------- |
| **DeepSeek**（推薦）              | DeepSeek 的 API key   | DeepSeek                           | 大部分人：最快、最準、很便宜 |
| **OpenRouter**                    | OpenRouter 的 API key | OpenRouter，再轉給你選的模型的公司 | 想換別家模型                 |
| **本機模型**（Ollama、LM Studio） | 自己裝模型，不用 key  | 不離開這台電腦                     | 不想讓文字離開電腦           |
| **其他相容 OpenAI 格式的服務**    | 該服務的網址和 key    | 你填的網址                         | 公司內部或自架的服務         |
| **不使用（全程本機）**            | 什麼都不用            | 不送出；只做「原話」               | 只要辨識，不要整理           |

每個服務的 key 分開存在鑰匙圈，換服務時不會把一家的 key 送給另一家。

### 用本機模型整理

1. 安裝 [Ollama](https://ollama.com) 並打開它。
2. 在「終端機」輸入 `ollama pull gemma4:e2b`，下載模型（約 4.6 GB）。
3. 在默契的「設定」→「潤稿服務」選「本機模型（Ollama、LM Studio）」，模型選 `gemma4:e2b`。

要知道的事：

- 膠囊會顯示「全程本機」，歷史紀錄也會記「沒有送出」。
- 比較慢：在 M3、16 GB 的 Mac 上，放開後約 2.5–4 秒出字；DeepSeek 約 1.5–2 秒。
- 專有名詞和英文詞不如 DeepSeek 準（我們用 30 段真人錄音比過，見 [評測](評測.md)）。
- 模型加上辨識模型約佔 6 GB 記憶體，8 GB 的 Mac 會很吃緊。
- 一段時間沒用，Ollama 會把模型收起來；默契在你按下說話鍵時就開始叫它回來，通常說完話時已經準備好。

## 在電腦之間同步

在「設定」→「在電腦之間同步」選一個雲端硬碟裡的資料夾（iCloud 雲端硬碟、Dropbox、OneDrive、Google Drive 都可以），另一台電腦的默契也選同一個資料夾。

- **會同步**：字典、語音片語、學到的改法、潤稿設定（潤飾程度、服務、模型）。
- **不會同步**：API key、錄音、歷史紀錄、使用統計。「從我的修改學習」的開關也是每台電腦各自決定。
- 默契只把檔案寫進那個資料夾，上傳和下載是雲端硬碟在做。

## 說話的小技巧

- **停頓沒關係**：句子之間停一下，默契會趁機先辨識前面那段，放開後等得更短。
- **說錯直接改口**：「禮拜三，不對，禮拜四」，整理後只留「禮拜四」。
- **口頭列點**：「第一…第二…第三…」在筆記 App 裡會變成清單。
- **英文照你平常說的**：不用刻意放慢或拼字，「幫我看 package.json 的 build script」會原樣留下英文。

## 常見問題

**按快捷鍵沒反應**
先確認選單列有默契的圖示，再確認「系統設定」→「隱私權與安全性」→「輔助使用」裡默契是打開的。更新後常見的狀況和解法見 [安裝教學的常見問題](安裝教學-Mac.md#常見問題)。

**第一個字常被吃掉**
打開「設定」→「提示音」，聽到「叮」再開口。

**更新後跳出鑰匙圈密碼視窗**
正常。默契沒有 Apple 的開發者簽章，macOS 會在每個新版本第一次讀取 API key 時問一次。輸入登入密碼、按「永遠允許」即可。

**某個 App 的場合判斷不對**
歡迎開 [issue](../../../issues/new/choose) 告訴我們 App 名稱，場合清單很容易補。

**支援 Windows 嗎？**
支援 Windows 10、11（64 位元），從 1.1.0 開始。說話鍵是右 Alt，其他用法都一樣。安裝方式見 [安裝教學（Windows）](安裝教學-Windows.md)。
