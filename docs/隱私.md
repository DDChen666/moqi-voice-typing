# 隱私

默契的承諾很簡單：**你的聲音不離開這台電腦；送出去的文字，每一筆你都看得到。**

## 什麼時候會連網

默契只會連到這幾個地方：

| 什麼時候                                | 連到哪裡                                  | 送出什麼                                          |
| --------------------------------------- | ----------------------------------------- | ------------------------------------------------- |
| 第一次打開                              | Hugging Face（`huggingface.co`）          | 只是下載辨識模型（約 1.5 GB），不送出任何你的資料 |
| 每次說話，且選了「整理」或「潤飾」      | 你選的潤稿服務（預設 `api.deepseek.com`） | 見下一節                                          |
| 在設定裡打開 OpenRouter 的「其他模型…」 | OpenRouter（`openrouter.ai`）             | 只是下載公開的模型清單，不送出任何你的資料        |

選「原話」或潤稿服務選「不使用」時，默契在下載完模型後完全不需要網路（「自動檢查更新」可以在設定裡關掉）。

「在電腦之間同步」不會讓默契自己連網：默契只把檔案寫進你選的資料夾，上傳和下載是你的雲端硬碟（OneDrive、Dropbox、Google Drive、iCloud）做的。

沒有帳號、沒有分析追蹤、沒有錯誤回報上傳。

「自動檢查更新」開著時（設定 → 一般），默契每 6 小時向 GitHub（`github.com`）下載一次最新版本的版本資訊（`latest.json`），不送出任何你的資料；有新版本時會問你要不要更新，不會自己安裝。

## 送去整理的是什麼

| 送出                             | 不送出                     |
| -------------------------------- | -------------------------- |
| 辨識出的文字                     | 你的聲音、錄音檔           |
| 你字典裡的詞（讓整理照你的寫法） | 你在哪個 App 打字          |
| 場合類別，例如「風格：聊天」     | 視窗標題、網址、檔名       |
|                                  | 你打字的輸入框裡原本的內容 |

- 場合是在你的電腦上判斷的，送出的只有類別。
- 開啟「選取文字時，用說的修改它」（預設關閉）後，按住說話鍵時如果有選取文字，**選取的文字會跟你說的話一起送出**，讓潤稿服務照你說的修改它。這一筆送出的字數也會算進「這次送出了什麼」和首頁的隱私卡。
- 設了「翻譯成」或某個 App 的額外要求時，那句話會送去潤稿服務處理，即使潤飾程度是「原話」。
- 潤稿服務選「本機模型（Ollama、LM Studio）」時，文字只送到這台電腦上的模型，不算送出。
- 每一次送出了什麼，都可以在「歷史紀錄」點開那一筆，看「這次送出了什麼」。
- 首頁的隱私卡顯示累計送出了多少字、送到哪裡。
- 潤稿服務怎麼處理收到的文字，依該服務的政策。預設的 DeepSeek 請參考它的[隱私政策](https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html)；在意的話可以換成你信任的服務，或選「不使用」。
- 選 OpenRouter 時，OpenRouter 會把文字轉給你選的模型的公司（例如 DeepSeek、Google、OpenAI）處理，依 OpenRouter 和那家公司的政策。
- 每個潤稿服務的 API key 分開存，換服務時不會把一家的 key 送給另一家。

## 資料放在哪裡

全部在你的 Mac 上：

| 資料       | 位置                                                                    | 說明                                                                   |
| ---------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 錄音       | `~/Library/Application Support/tw.yuyin.dictation/recordings/`          | 最近 100 次，可以在歷史紀錄逐筆刪除                                    |
| 歷史紀錄   | 同上，`history.db`                                                      | 辨識原文與整理後的文字                                                 |
| 使用統計   | 同上，`yuyin_timings.jsonl`                                             | 只有時間、字數、App 名稱、送出字數，**沒有內容**；刪掉歷史紀錄時一起刪 |
| 字典、設定 | 同上，`yuyin.json`、`settings_store.json`                               |                                                                        |
| 學到的改法 | 同上，`yuyin_learned.json`                                              | 只有改過的詞（例如「蘇帕貝斯 → Supabase」），沒有整段文字              |
| 辨識模型   | `~/.cache/huggingface/hub/models--handy-computer--Qwen3-ASR-1.7B-gguf/` | 約 1.5 GB，第一次開啟時從 Hugging Face 下載                            |
| 日誌       | `~/Library/Logs/tw.yuyin.dictation/`                                    | 辨識出的文字會被遮蔽成 `[REDACTED]`                                    |
| API key    | macOS 鑰匙圈（服務名稱 `tw.yuyin.dictation`）                           | 每個潤稿服務一筆；不寫進任何檔案；App 的介面只能設定，不能讀回         |

## 在電腦之間同步（預設關閉）

在「設定 → 在電腦之間同步」選一個雲端硬碟裡的資料夾，另一台電腦也選同一個，就會同步：

- **會同步**：字典、學到的改法、潤稿設定（潤飾程度、服務、網址、模型）。
- **不會同步**：API key（每台電腦各自存）、錄音、歷史紀錄、使用統計，以及「從我的修改學習」的開關（每台電腦各自決定）。
- 每台電腦只寫自己的檔案：`<你選的資料夾>/Moqi/<這台電腦的代號>.json`。檔案裡有字典、學到的改法和設定，可以直接打開看。
- 停止同步後，這台電腦的檔案會留在資料夾裡，讓其他電腦保有它分享過的內容；不需要的話可以自己刪掉。

## 權限為什麼需要

- **麥克風**：聽你說話。只在你按住快捷鍵（或免持模式）時錄音。
- **輔助使用**：偵測全域快捷鍵、把字貼到游標處，並判斷前景 App 以決定場合；開啟「從我的修改學習」時，也用來讀取剛貼上字的那個輸入框。默契不會讀取密碼欄。

## 全部刪除

1. 選單列的默契圖示 →「結束」。
2. 把「應用程式」裡的默契丟到垃圾桶。
3. 刪掉 `~/Library/Application Support/tw.yuyin.dictation` 和 `~/Library/Logs/tw.yuyin.dictation`。
4. 刪掉辨識模型 `~/.cache/huggingface/hub/models--handy-computer--Qwen3-ASR-1.7B-gguf`（同一層的其他資料夾屬於其他軟體）。
5. 在「鑰匙圈存取」搜尋 `tw.yuyin.dictation`，刪掉那一筆。

## 從你的修改學習（預設關閉）

開啟「設定 → 從我的修改學習」後，默契會從你改正它打的字學習，例如你把「蘇帕貝斯」改成「Supabase」。同樣的改法出現兩次，之後就自動照你的改。

- **預設關閉**。用過幾次後，首頁會問你一次要不要開啟；之後隨時可以在設定裡關掉。
- 開啟時，默契在貼上後的幾分鐘內（最多 3 分鐘，你改完、送出或離開那個輸入框就停止）讀取那個輸入框，在記憶體裡比對你改了哪些字，比完就丟掉。
- **只保存改過的詞**（`yuyin_learned.json`），不保存整段文字。學到的英文詞會加進你的字典。
- 不讀密碼欄，什麼都不送出。
- 學到的每一筆都列在「字典」頁，可以刪除；刪除的改法不會再學。

## 開發用的可行性記錄（預設關閉）

原始碼裡有一個 `field_probe` 模組，是為了評估「從你貼上後的修改學習打字習慣」可不可行而寫的。

- 只有在資料夾裡手動建立 `yuyin_field_probe.on` 這個檔案時才會啟動，一般使用者不會碰到。
- 啟動時也只記錄「輸入框讀不讀得到、有沒有看到貼上的字、有沒有被修改、有沒有送出」這幾個是或否，**不存任何文字**，也不送出。
- 這是開發時用的工具，跟上面的「從我的修改學習」是分開的。
