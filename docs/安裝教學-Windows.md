# 在 Windows 上安裝默契

大約 10 分鐘，其中大半是等辨識模型下載。

## 先看一下

- **需要**：
  - Windows 10 或 Windows 11（64 位元）。
  - 約 2 GB 空間放辨識模型。
  - 建議有獨立顯示卡（NVIDIA、AMD 或 Intel Arc）。沒有也能用，只是辨識比較慢。
- **目前只在** Windows 11、RTX 4070 12 GB、32 GB 記憶體上完整測試過。
- **為什麼第一次打開要多幾步**：
  - 默契是免費的開源軟體，沒有購買程式碼簽章憑證，所以 Windows 認不得它，第一次打開安裝檔時會跳出藍色的警告視窗。
  - 這是 Windows 對所有沒有簽章的程式的做法，不代表軟體有問題。原始碼全部公開在這個頁面，可以自己檢查，也可以自己編譯。
  - 每次下載新版本的安裝檔都會再出現一次，照第 2 節的做法就好。

## 1. 下載安裝檔

1. 到本頁的 [Releases](../../../releases) 下載最新的 `Moqi_x.y.z_x64-setup.exe`。
2. 如果瀏覽器擋下這個檔案（例如說它「不常下載」），在瀏覽器的下載清單裡找到它，選「保留」。

## 2. 執行安裝檔

1. 雙擊下載好的 `Moqi_x.y.z_x64-setup.exe`。
2. 會跳出藍色的「**Windows 已保護您的電腦**」視窗，寫著「Microsoft Defender SmartScreen 已防止某個無法辨識的應用程式啟動」。按那段文字下面的「**其他資訊**」。
3. 視窗會多出「應用程式：Moqi_x.y.z_x64-setup.exe」「發行者：不明的發行者」，右下角多一個「**仍要執行**」按鈕。按「**仍要執行**」。
   - 不要按「不要執行」。
4. 「歡迎使用 Moqi 安裝精靈」：按「**下一步(N)**」。
5. 「選取安裝位置」：不用改，按「**下一步(N)**」，就會開始安裝。
   - 不需要系統管理員權限，只裝給目前這個帳號使用。
6. 「完成安裝」：按「**下一步(N)**」。
7. 「即將完成安裝 Moqi」：「執行 Moqi」和「在桌面建立捷徑」都勾著，按「**完成(F)**」，默契就會打開。

更新時如果默契還開著，會跳出「Moqi 正在執行。按「確定」結束它。」，按「**確定**」即可。

## 3. 第一次開啟的三步

默契打開後會帶你完成三步：

1. **麥克風和辨識模型**
   - **麥克風**：通常已經是「已允許」。如果顯示按鈕，按下去會打開 Windows 的「設定」→「隱私權與安全性」→「麥克風」，把「麥克風存取」和「允許傳統型應用程式存取您的麥克風」都打開。
   - **辨識模型**（約 1.5 GB）這時已經在背景下載，視網路速度要幾分鐘。下載完才能按「繼續」。
   - Windows 版不需要「輔助使用」之類的權限，這一步只有這兩項。
2. **選「原話」或「整理」**：
   - 原話：完全在這台電腦上處理，不需要任何帳號。
   - 整理：會把辨識出的文字送去整理。要貼 API key，也可以先略過，之後在設定裡再填。
3. **試說一句**：按住鍵盤右邊的 **Alt** 鍵，說一句話，放開。看到字出現就完成了。

完成後，默契會待在螢幕右下角的系統匣（時鐘旁邊，一個黑底白色聲波的小圖示）。關掉視窗不會結束它，平常也不用打開視窗。

- Windows 11 會先把新程式的圖示收起來：按工作列右邊的「^」（顯示隱藏的圖示）就看得到。想一直看得到，把默契的圖示拖到「^」外面的工作列上。

## 之後怎麼更新

1. 在系統匣的默契圖示上按右鍵 →「結束」。
2. 下載新版的安裝檔，照第 2 節安裝。設定和歷史紀錄都會保留。

## 移除

1. 在系統匣的默契圖示上按右鍵 →「結束」。
2. 打開「設定」→「應用程式」→「已安裝的應用程式」，找到「Moqi」，按右邊的「⋯」→「解除安裝」。
3. 「Moqi 解除安裝」視窗裡有一個「一併刪除設定、歷史紀錄和錄音」，看完下面再按「**解除安裝(U)**」：
   - 想完全移除就勾起來。
   - 之後還會再裝回來的話，不要勾，設定和歷史會保留。
4. 辨識模型（約 1.5 GB）另外放在 Hugging Face 的共用資料夾：
   - 按 Win + R，貼上 `%USERPROFILE%\.cache\huggingface\hub`，按 Enter，把 `models--handy-computer--Qwen3-ASR-1.7B-gguf` 刪掉。
   - 同一個資料夾裡的其他項目屬於其他軟體，不要動。
5. 有填過 API key 的話，key 存在「認證管理員」裡：
   - 按開始，搜尋「認證管理員」打開，選「Windows 認證」，找到含有 `tw.yuyin.dictation` 的項目，展開後按「移除」。

## 常見問題

**按右 Alt 沒反應**

- 先確認系統匣有默契的圖示（沒有的話，從開始選單打開「默契 Moqi」）。
- 正在用「以系統管理員身分執行」的程式（例如系統管理員的終端機）時，Windows 不讓一般程式的快捷鍵作用。在一般的視窗裡就能用。
- 在「設定」頁可以把快捷鍵換成別的鍵。

**說話了但沒有字**

- 「設定」→「隱私權與安全性」→「麥克風」，確認「麥克風存取」和「允許傳統型應用程式存取您的麥克風」都是開的。
- 在默契的「設定」裡確認選對了麥克風。
- 剛裝好時辨識模型可能還在下載（第一次開啟的第 1 步看得到進度），等下載完成再試。

**字貼到別的地方了**

- 按下快捷鍵之後換了視窗，默契不會亂貼，而是複製起來，膠囊會顯示「已複製，請自己貼上」。在要的地方按 Ctrl + V 就好。
- 也可以在系統匣的默契圖示上按右鍵 →「貼上上一次」。

**在開始選單找不到**

- 開始選單搜尋「默契」或「Moqi」都找得到。

**按 Win + V 會看到我說的話嗎？**

- 不會。默契貼上時會標記「不要留在剪貼簿紀錄」，貼完也會把你原本剪貼簿裡的東西放回去。

**有沒有把我的聲音傳出去？**

- 沒有。辨識全程在這台電腦上完成。
- 選「整理」或「潤飾」時，送出去的只有辨識出的文字和你字典裡的詞。
- 每一次送出了什麼，都可以在「歷史紀錄」點開那一筆查看。
