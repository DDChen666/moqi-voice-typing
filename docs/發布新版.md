# 發布新版

默契會在「自動檢查更新」開著時，每 6 小時讀一次這個網址：

```
https://github.com/DDChen666/moqi-voice-typing/releases/latest/download/latest.json
```

也就是 GitHub 上**最新一個正式 Release** 裡的 `latest.json`。裡面寫著版本號，以及每個平台安裝檔的網址和簽章。默契會先用內建的公鑰確認簽章，確認無誤才安裝，所以只有握有私鑰的人發的更新才裝得上去。

## 一次性的準備：更新用的金鑰

- 私鑰：`%USERPROFILE%\.moqi-signing\moqi-updater.key`（Windows）、`~/.moqi-signing/moqi-updater.key`（Mac，權限 600）。**絕對不要放進 repo。**
- 公鑰：已經寫在 `src-tauri/tauri.conf.json` 的 `plugins.updater.pubkey`。
- **一定要備份私鑰**，例如放進密碼管理器。弄丟的話，已經安裝的默契就收不到之後的更新，只能請大家手動重裝。
- Mac 也要發版的話，把同一把私鑰安全地複製到 Mac 上（例如透過密碼管理器），不要用聊天軟體或 email 傳。
- 想加密碼保護：重新產生一把有密碼的金鑰，換掉公鑰，並在第一次發版**之前**完成。發版時用 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` 提供密碼。

## 每次發版

1. **改版本號**：`package.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml` 三個地方要一致（例如 `1.1.0`）。
2. **Windows**：在 PowerShell 執行

   ```powershell
   .\scripts\windows\release.ps1 -Notes "這一版改了什麼"
   ```

   完成後 `dist-release\` 會有三個檔案：`Moqi_1.1.0_x64-setup.exe`、它的 `.sig`、`latest.json`。

3. **Mac**：把 Windows 產生的 `latest.json` 複製到 Mac，在 Mac 上執行

   ```sh
   APPLE_SIGNING_IDENTITY="Moqi Dev" scripts/macos/release.sh --notes "這一版改了什麼" --latest 路徑/latest.json
   ```

   完成後 `dist-release/` 會有 `Moqi_1.2.0_aarch64.dmg`（新安裝用）、`Moqi_1.2.0_aarch64.app.tar.gz` 和它的 `.sig`（自動更新用），以及加入 `darwin-aarch64` 的 `latest.json`。兩個平台要放在**同一個** `latest.json`，上傳這一份。
   - `APPLE_SIGNING_IDENTITY` 要用每次都相同的簽章，使用者更新後才不用重新授權麥克風和輔助使用（見 BUILD.md）。
4. **建立 GitHub Release**：GitHub → Releases → Draft a new release
   - Tag：`v1.1.0`（跟 `latest.json` 裡安裝檔網址的 `v1.1.0` 一致）。
   - 上傳：Windows 安裝檔、Mac 的 `.dmg` 和 `.app.tar.gz`、`latest.json`。`.sig` 可以不傳，簽章已經寫在 `latest.json` 裡。
   - 確認無誤再按 **Publish release**。草稿（Draft）和預先發布（Pre-release）不會被當成「最新版」，可以先用來檢查。
5. **確認**：在一台裝舊版的電腦打開默契 →「設定 → 一般 → 自動檢查更新 → 立即檢查」，應該會看到新版本。

## 程式碼簽章（讓 SmartScreen 不再擋）

上面的「更新簽章」只是確認更新檔是你發的，跟 Windows 的「程式碼簽章」是兩回事。沒有程式碼簽章時，每個新版本第一次下載都會出現 SmartScreen 的「Windows 已保護您的電腦」。

| 做法                      | 費用（大約）        | 說明                                                                                 |
| ------------------------- | ------------------- | ------------------------------------------------------------------------------------ |
| Certum 開源程式碼簽章憑證 | 每年數十歐元        | 給開源開發者的個人憑證，要驗證身分。                                                 |
| Azure Trusted Signing     | 每月約 10 美元      | 雲端簽章，但對個人申請者的國家和資歷有限制，要先確認能不能申請。                     |
| SignPath Foundation       | 免費（開源專案）    | 要申請，而且通常要求用 GitHub Actions 這類公開的建置流程，目前 repo 沒有開 Actions。 |
| 一般 OV 憑證              | 每年約 200 美元以上 | 商業憑證。                                                                           |

拿到憑證後，在 `src-tauri/tauri.windows.conf.json` 的 `bundle.windows` 加上 `signCommand`（或 `certificateThumbprint`），`release.ps1` 編出來的安裝檔就會有簽章。注意：就算有簽章，SmartScreen 也要累積一段時間的下載量才會完全不擋。

Mac 的對應做法是 Apple Developer 帳號（每年 99 美元）加上公證（notarization），請 Mac 端處理。
